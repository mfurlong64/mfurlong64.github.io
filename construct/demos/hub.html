Recession chatter on Hacker News

How often do recession-signal keywords appear in HN stories per day?
layoffsrecessionunemploymentbankruptcy
14 rows · 4.812 GB scanned
SQL
SELECT DATE(timestamp) AS day,
  COUNTIF(REGEXP_CONTAINS(LOWER(title),'layoff')) AS layoffs,
  COUNTIF(REGEXP_CONTAINS(LOWER(title),'recession')) AS recession,
  COUNTIF(REGEXP_CONTAINS(LOWER(title),'unemployment')) AS unemployment,
  COUNTIF(REGEXP_CONTAINS(LOWER(title),'bankrupt')) AS bankruptcy
FROM `bigquery-public-data.hacker_news.full`
WHERE DATE(timestamp) >= DATE_SUB(CURRENT_DATE(), INTERVAL 14 DAY)
GROUP BY day ORDER BY day

Air quality: worst countries by PM2.5

Which countries have the highest average PM2.5 readings?
12 rows · 0.089 GB scanned · cached
SQL
SELECT country, ROUND(AVG(value),1) AS avg_pm25, COUNT(*) AS readings
FROM `bigquery-public-data.openaq.global_air_quality`
WHERE parameter = 'pm25' AND value BETWEEN 0 AND 1000
GROUP BY country HAVING readings > 500
ORDER BY avg_pm25 DESC LIMIT 12

GDP growth: China vs USA vs Germany

How has annual GDP growth compared across three major economies?
ChinaGermanyUSA
18 rows · 0.021 GB scanned
SQL
SELECT country_name, year, ROUND(value,2) AS gdp_growth
FROM `bigquery-public-data.world_bank_wdi.indicators_data`
WHERE indicator_code = 'NY.GDP.MKTP.KD.ZG'
  AND country_name IN ('China','United States','Germany')
  AND year BETWEEN 2015 AND 2020
ORDER BY country_name, year

SQL
SELECT year, ROUND(severely_burdened/1e6,2) AS severely_burdened,
