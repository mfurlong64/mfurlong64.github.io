dbt-agent

A dbt project that deliberately contains no models. It holds 39 tests and 8 freshness checks over the platform's clean layer as sources, so it is a statement of what must be true of the data and nothing else. The modelling stays in one place next door, with declared grains and deterministic keys.

Playroom

A 3D rigid-body physics engine in plain JavaScript, no library underneath: substepped sequential impulses with restitution and Coulomb friction, position correction with a 4 mm skin, per-island sleep via union-find, rope and rod joints, buoyant water. three.js only draws. 71 physics tests run headless in node; every room benchmarks above 500 fps except a generated 47-metre marble run.

Notes from building the platform

Short, specific lessons, each one paid for with a wrong number that looked right. All twelve are here.

01

The latest partition is not the widest one

MAX(ingested_date) was wrong three times, for three different reasons. Incremental feeds put only the delta in the newest partition.

 02

Uniqueness is not correctness

Two dimensions passed every grain check while reporting twice the flown launches that existed.

 07

A hand-typed number fails the build

After a board's thesis contradicted its own chart, every figure in a walkthrough is derived from the tile beside it.
